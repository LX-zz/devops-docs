# Аварийное восстановление

## Диагностика

1. Открыть GitHub Actions.
2. Найти неудачный запуск Publish documentation.
3. Изучить журнал Build documentation.
4. Определить причину ошибки.

## Восстановление

1. Исправить отсутствующие документы и неправильные ссылки.
2. Проверить документацию командой mkdocs build --strict.
3. Создать Pull Request.
4. Дождаться успешного CI.
5. Объединить изменения с main.
6. Проверить опубликованный сайт.
